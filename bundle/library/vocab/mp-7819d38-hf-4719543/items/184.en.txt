// Extreme close-up / エクストリームクローズアップ
// Pack: camera2 (Camera moves & transitions, part 2) · element 16 · Category: Angles & Framing
// What happens: From a close-up of the face to a frame filled by nothing but the eyes.
// Motion spec:
//   - Camera: the face's right eye (0.06 m left of centre, 1.66 m high) 1.3 m ahead is placed at the centre of frame; the camera does not move
//   - Focal length: 610 px → 2040 px (shown as 44mm → 148mm, about 3.3×); f = 610 × (2040/610)^p, where p is a cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)) from 0.5 s to 3.4 s
//   - Face: a blue head (radius 0.16 m) with white eyes (ellipses 0.045×0.028 m), dark pupils (radius 0.016 m), highlights and white brows; it starts as a close-up of the whole face (head about 150 px across) and ends with only the eyes filling the frame
//   - Background: trees and buildings blurred 3 px, leaving the frame as the lens closes in
//   - Return: hold 3.4–4.2 s, then cross-fade back to the start over the last 0.5 s; top-right readout shows the focal length and the abbreviation (44mm CU → 148mm ECU)
// When to use it: For the emotional peak, or to make the viewer notice one small detail.
// Tags: extreme close-up, ecu, close-up, eye, detail, macro, framing
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// Live demo: https://showheyohtaki.github.io/motion-prompt/#184
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 16
// 16 エクストリームクローズアップ: 顔のクローズアップから、目だけが画面を埋めるまで寄る
CELLS[15] = shot(camCell((k, w, h, p) => {
  const f = 610 * Math.pow(2040 / 610, p);
  world(k, w, h, cam({ f, x: -0.06, y: 1.66 }), {
    blurBg: 3, trees: true,
    extra: [[0, 0, 1.3, (kk) => {   // 目のある顔
      person(kk, 1);
      [[-0.06, 1.66], [0.06, 1.66]].forEach(([x, y]) => { kk.fillStyle = '#fff'; kk.beginPath(); kk.ellipse(x, y, 0.045, 0.028, 0, 0, 7); kk.fill(); kk.fillStyle = C.ink; kk.beginPath(); kk.arc(x + 0.008, y, 0.016, 0, 7); kk.fill(); kk.fillStyle = '#fff'; kk.beginPath(); kk.arc(x + 0.014, y + 0.007, 0.005, 0, 7); kk.fill(); kk.strokeStyle = '#fff'; kk.lineWidth = 0.012; kk.beginPath(); kk.arc(x, y + 0.02, 0.05, Math.PI * 1.15, Math.PI * 1.85); kk.stroke(); });
    }]]
  });
}, p => `${mm(610 * Math.pow(2040 / 610, p))} ${p > 0.85 ? 'ECU' : 'CU'}`));
