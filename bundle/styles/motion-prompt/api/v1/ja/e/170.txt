// バレルロール / Barrel roll
// パック: camera2 (カメラワークと切り替え 第2弾) · element 02 · カテゴリ: カメラの動き
// 何が起きるか: カメラがレンズの軸でぐるりと1回転し、地平線が一周して元に戻る。
// 動きの仕様:
//   - カメラ: 位置固定（高さ1.5m）。ロールだけ 0 → 2π rad（360°）。画面の中央を軸に全体が1回転
//   - 時間: 0.5秒から3.6秒まで3.1秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 被写体: 人物は7m先で動かない。地平線・建物・人物がそろって同じ角度だけ回る。回っている間は画面の四隅に白が見える
//   - 止め: 3.6〜4.2秒。1回転した状態は開始と同じ絵なので、最後の0.5秒のクロスフェードは見えない（1周4.7秒）
//   - 右上に角度を表示（↻ 0° → ↻ 360°）
// 使いどころ: 飛行機やドローンの映像で勢いを出すとき、めまいや混乱を表すとき。
// タグ: barrel roll, roll, 360, rotate, spin, aerial, camera move
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#170
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 02
// 02 バレルロール: レンズの軸（画面の中央）でカメラを1回転
CELLS[1] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ roll: p * Math.PI * 2 }), { person: { z: 7 } }),
  p => `↻ ${Math.round(p * 360)}°`, 0.5, 3.6));
