// パック: camera2 (カメラワークと切り替え 第2弾) · element 09 · カテゴリ: アングル・画づくり
// 何が起きるか: カメラを地面近くまで下げて見上げる。人物が大きく、建物が高くそびえて見える。
// 動きの仕様:
//   - カメラ: 高さ 1.5m → 0.35m へ下げながら、ピッチ 0 → +0.32rad（約18°上向き）。位置の前後は動かない
//   - 時間: 0.6秒から2.2秒まで1.6秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 被写体: 人物は4.5m先で動かない。左3m・奥22mに高さ11.8mの塔。見上げるにつれ人物と塔が画面の上へ伸び、地平線は下がる
//   - 止め: 2.2〜4.2秒はローアングルのまま保つ（構図そのものを見せる時間）
//   - 戻り: 最後の0.5秒で目の高さへクロスフェード（1周4.7秒）。右上に角度と高さ（↗ 0° · 1.5m → ↗ 18° · 0.4m）
// 使いどころ: 人物を強く・大きく見せたいとき、建物の高さを強調するとき。
// タグ: low angle, worm's eye, look up, from below, power, heroic, angle
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#177

// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 09
// 09 ローアングル: カメラを地面近くに下げ、見上げる。人物が大きく、建物が高く見える
CELLS[8] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ y: lerp(1.5, 0.35, p), pitch: lerp(0, 0.32, p) }), { person: { z: 4.5 }, tower: [-3, 22] }),
  p => `↗ ${Math.round(lerp(0, 0.32, p) * 57.3)}° · ${lerp(1.5, 0.35, p).toFixed(1)}m`, 0.6, 2.2));
