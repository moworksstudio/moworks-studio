// ペデスタル / Pedestal
// パック: camera2 (カメラワークと切り替え 第2弾) · element 01 · カテゴリ: カメラの動き
// 何が起きるか: カメラが向きを変えずに真上へ平行移動する。地平線は画面の中央のまま、人物と建物が下へ流れる。
// 動きの仕様:
//   - カメラ: 高さ 1.0m → 3.2m へ真上に平行移動。向き（ヨー・ピッチ）と焦点距離（330px）は固定
//   - 時間: 0.5秒から3.4秒まで2.9秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 被写体: 人物は7m先で動かない。画面上では下へ流れ、足元から画面の外へ切れていく。右3.5m・奥26mに塔
//   - ピッチを変えないので地平線は画面の中央から動かない（#031 クレーンアップは下を向きながら上がる）
//   - 戻り: 3.4〜4.2秒は止め、最後の0.5秒で開始状態へクロスフェード（1周4.7秒）
//   - 右上に高さを表示（↕ 1.0m → ↕ 3.2m）
// 使いどころ: 棚や建物を下から上へなめらかに見せるとき、ティルトせずに目線の高さを変えるとき。
// タグ: pedestal, boom, vertical move, rise, elevate, camera move, no tilt
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#169
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 01
// 01 ペデスタル: カメラごと真上へ平行移動。向き（ピッチ）は変えないので地平線は画面の中央のまま（#031 クレーンアップとの違い）
CELLS[0] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ y: lerp(1.0, 3.2, p) }), { person: { z: 7 }, tower: [3.5, 26], buildings: true }),
  p => `↕ ${lerp(1.0, 3.2, p).toFixed(1)}m`));
