「クロスカッティング（Cross-cutting）」を使ってください。「カメラワークと切り替え 第2弾」の名前の1つです。
Motion Prompt #190

どういうものか: 同時に進む2つの場面を交互に
見本で起きること: 同時に進む2つの場面（走る人物と走る車）を、だんだん短く交互に見せる。
仕様:
- 2つの場面が同じ時刻を進む: A は走る人物（左0.3m、奥 15m → 4.5m、脚は u×12）、B は街を走る車（右1m、奥 17m → 4.5m）。どちらも4.7秒でカメラに近づく
- カット: 0 / 1.1 / 2.0 / 2.7 / 3.3 / 3.8 / 4.2 / 4.5秒で A・B を交互に直結。1.1 → 0.9 → 0.7 → 0.6 → 0.5 → 0.4 → 0.3秒と短くなり緊張を上げる
- 映っていない間もその場面の時間は進んでいる（戻ったとき位置が先に進んでいる）
- カメラ: Aは高さ1.3m・固定、手前に杭4本。Bは高さ1.6m・ピッチ+0.06rad・固定、街と太陽
- 画面下の帯: A（灰）B（青）が交互に並ぶ8区間と再生ヘッド。最後の0.3秒でAの開始状態へクロスフェード
- 右上に「SCENE A」「SCENE B」
使いどころ: 追跡や救出など、同時進行の緊張を高めるとき。
