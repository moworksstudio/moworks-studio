「ディープフォーカス（Deep focus）」を使ってください。「カメラワークと切り替え 第2弾」の名前の1つです。
Motion Prompt #182

どういうものか: 手前から奥まで全部にピント
見本で起きること: 手前の花から奥の人物・建物まで、同時に全部にピントが合っていく。
仕様:
- カメラ: 位置・向き・焦点距離すべて固定（高さ1.1m）。変わるのはぼかしの量だけ
- ぼかし: 手前の花（左0.75m・奥2m）を 5px → 0px、奥（人物は右0.9m・奥9m、建物、山）を 6px → 0px。両方同時にはっきりしていく（#033 ラックフォーカスは片方がぼける）
- 時間: 0.5秒から3.4秒まで2.9秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
- ピント枠: 花（半辺46px）と人物（半辺30px）の両方に青い四隅の枠を、ピントが合うにつれ不透明度 0 → 1 で出す
- 戻り: 3.4〜4.2秒は止め、最後の0.5秒で開始状態へクロスフェード。右上に絞り値（f/1.8 → f/16）
使いどころ: 画面のどこを見てもよい場面、奥行きの中で複数の出来事を同時に見せるとき。

共通の補助コード: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
