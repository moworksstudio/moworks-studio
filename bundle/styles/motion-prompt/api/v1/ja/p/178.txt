「ハイアングル（High angle）」を使ってください。「カメラワークと切り替え 第2弾」の名前の1つです。
Motion Prompt #178

どういうものか: 高い位置から見下ろして撮る
見本で起きること: カメラを高い位置へ上げて見下ろす。人物が小さく、地面が画面の大半を占める。
仕様:
- カメラ: 高さ 1.5m → 4.5m へ上げながら、ピッチ 0 → -0.5rad（約29°下向き）。位置の前後は動かない
- 時間: 0.6秒から2.2秒まで1.6秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
- 被写体: 人物は5m先で動かない。見下ろすにつれ人物が小さく下がり、地面の格子が画面の大半を占め、地平線は上へ抜ける
- 止め: 2.2〜4.2秒はハイアングルのまま保つ（#031 クレーンアップは9mまで上がり続ける。13 バーズアイは真下90°）
- 戻り: 最後の0.5秒で目の高さへクロスフェード（1周4.7秒）。右上に角度と高さ（↘ 0° · 1.5m → ↘ 29° · 4.5m）
使いどころ: 人物を弱く・小さく見せたいとき、状況を俯瞰で説明するとき。
