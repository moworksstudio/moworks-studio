「ロックオフ（Locked-off shot）」を使ってください。「カメラワークと切り替え 第2弾」の名前の1つです。
Motion Prompt #175

どういうものか: カメラは固定で被写体だけ動く
見本で起きること: 三脚で固定したカメラの前を人物が横切り、奥を車が通る。カメラは1pxも動かない。
仕様:
- カメラ: 完全に固定（高さ1.4m、正面向き、焦点距離330px）。動くのは被写体だけ
- 被写体: 人物が6.5m先を左から右へ等速で横切る（x = -6.2m → +6.2m、4.7秒）。脚と腕は sin(u×7)×0.42rad
- 奥15mを灰色の車が右から左へ横切る（x = +16m → -16m、4.7秒）
- どちらも開始と終了の位置は画面の外なので、4.7秒ごとに継ぎ目なくくり返す
- 左下に三脚の印（灰色）。右上に「LOCKED」（#040 フリーズフレームは映像の時間が止まる。ここは時間が流れ、カメラだけが止まっている）
使いどころ: 動きの対比で被写体を目立たせるとき、定点観測、タイムラプスや合成の土台にするとき。
