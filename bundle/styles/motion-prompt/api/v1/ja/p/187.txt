「フェードアウト（Fade to black）」を使ってください。「カメラワークと切り替え 第2弾」の名前の1つです。
Motion Prompt #187

どういうものか: 画面が暗くなって終わる
見本で起きること: 画面全体が黒へ沈んで終わり、黒から次の場面が明けてくる。
仕様:
- フェードアウト: 1.4秒から2.6秒までの1.2秒で、前の絵の上に黒（rgb(20,20,24)）を不透明度 0 → 100% で重ねる。2次のイーズインアウト（cubic-bezier(0.45,0,0.55,1) 相当）
- 黒: 2.6〜3.1秒は真っ黒。2.9秒に、見えないまま次の絵へ直結で切り替える
- フェードイン: 3.1秒から4.3秒までの1.2秒で黒の不透明度を 100% → 0 に。同じイージング
- カメラ: 両方の絵とも固定（Aは高さ1.4m、Bは高さ1.6m・ピッチ+0.1rad）。被写体も動かない
- 4.7秒ごとに A→B、B→A を交互に行う（往復で9.4秒）。右上に「FADE OUT」「FADE IN」。ファインダーの枠は黒の上にも残す
使いどころ: 章の区切り、時間の大きな経過、物語の終わり。
