「モンタージュ（Montage）」を使ってください。「カメラワークと切り替え 第2弾」の名前の1つです。
Motion Prompt #192

どういうものか: 短いカットを重ねて時間を縮める
見本で起きること: 7つの短いカットで30日分の練習を見せる。つなぎは直結で、右上の日付が飛ぶ。
仕様:
- 7つのカットを直結（0フレーム）で並べる: 0.75 / 0.7 / 0.65 / 0.65 / 0.65 / 0.6 / 0.7秒（計4.7秒）。右上の日付が DAY 1 → 3 → 7 → 12 → 20 → 28 → 30 と飛ぶ
- カット: 1 走る人物をトラッキング（脚は t×14）、2 公園でジャンプ、3 日の出（太陽が高さ4m → 12m）、4 ローアングルで両腕を上げる、5 街を歩く（焦点距離420px）、6 人物の周りを -0.3 → +0.3rad 回り込む、7 旗の前で両腕を上げる
- 全部で30日の練習を4.7秒に縮める。カットごとにカメラの位置・高さ・焦点距離が変わる（#041 ジャンプカットは同じ画角のまま）
- 画面下の帯: 7区間、映っているカットだけ青。最後の0.3秒で最初のカットの開始状態へクロスフェード
使いどころ: 長い期間の変化や努力を短く見せるとき。
