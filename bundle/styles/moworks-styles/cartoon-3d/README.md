# 3D Cartoon Animation Toolkit

> **First time?** Open this folder in Claude Code and type **`set this up`**. The AI checks that Node.js, ffmpeg, uv
> and Remotion are installed, asks you to install anything missing, then renders a 5-second demo in each format.

Narrated **3D cartoon videos**, made by your AI agent with code:
- an original flat-drawn cast (Mika, Ravi, June, Otto, and new characters you design together)
- toon-lit sets, thick ink outlines, glowing props, cinematic depth of field
- word-by-word captions synced to the voice-over
- sound effects designed in code, mastered for YouTube (−14 LUFS)

Delivered as an **MP4**: 9:16 (1080×1920) for Shorts, Reels and TikTok, or 16:9 (1920×1080) for YouTube.

## What you can make (switch modules on or off any time: *"switch the music module on"*)
| Module | You get |
|---|---|
| **Any 3D cartoon clip** (always on) | a scene, a 10-second clip, your voice-over animated |
| **Story Shorts (9:16)** | 40–60 s narrated mini-stories in five proven formats |
| **What-If Stories (16:9)** | 30–50 s "What if you…?" pieces and 8–12 minute chaptered episodes |
| **AI voice** | your script voiced by a connected text-to-speech MCP (or use your own recording) |
| **Idea Lab** | video ideas for your niche, researched facts, titles, descriptions, tags, chapters |
| **Character & Set Builder** | new original characters, costumes, props and reusable sets |
| **Fresh-eyes Review** | a second AI checks every finished video frame by frame before you see it |
| **Original Music** | music composed in code for your video, only when you ask |

## Use it
Talk to the AI in this folder:
> Give me 10 short ideas about everyday science.

> Make a 60-second short about why supermarkets put the milk at the back. Write the script first.

> Make a 45-second What If: what if you never needed sleep?

> Here's my voice-over (drag the MP3 in). Animate it as a 9:16 short.

> Make a new character: a grumpy chef who runs the office canteen.

It writes the script first, shows you still frames, then exports to `out/`.
- **Demos**: `out/DemoTall/DemoTall.mp4` and `out/DemoWide/DemoWide.mp4` (made at setup).
- **Your taste**: say *"save that"* when a note should apply to every future video.
- **Problems**: say *"run the doctor"*. It lists anything missing, with the command that installs it.
- **How it works**: `HOW-IT-WORKS.md`.
